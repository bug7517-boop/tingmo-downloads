# 聽墨

YouTube・Bilibili 影片轉文字、時間戳、繁體中文翻譯與摘要。

> 公開下載名稱已更新為「聽墨」。v1.2.0 安裝包保持原版本，檔名仍為 VideoTextBot，程式內仍可能顯示「影片轉文字機器人」；功能與已確認可用的版本相同。

## 朋友安裝 Chrome 版：不需要 Python

適用 Windows 64 位元與 Chrome。請到 [v1.2.0 預覽版下載頁](https://github.com/bug7517-boop/tingmo-downloads/releases/tag/v1.2.0-chrome-preview)，在 **Assets** 下載 **`VideoTextBot-Windows-v1.2.0-preview.zip`**。不要選 GitHub 自動產生的 Source code ZIP；單獨的 Chrome ZIP 也不包含轉錄服務。

> 這是公開下載專案，任何人皆可下載；原始碼開發專案另行保留。此版本尚未上架 Chrome 商店。
### 第一次安裝與連線

1. 完整解壓縮 Windows ZIP 到固定資料夾，例如 `C:\AI-Tools\VideoTextBot`；不要在壓縮檔內執行，也不要在安裝後刪除資料夾。
2. 雙擊 **`啟動擴充功能服務.cmd`**，等待本機連線頁開啟，使用期間保持服務執行。
3. Chrome 網址列輸入 `chrome://extensions`，開啟「開發人員模式」，點「載入未封裝項目」，選擇解壓縮資料夾中的 **`chrome-extension`**。這不是舊桌面版的 `browser-companion`。
4. 開啟或重新整理 YouTube／Bilibili 影片頁面，點右下角「影片轉文字」，或 Chrome 工具列的擴充功能圖示。
5. 在工具面板的「本機服務連線」貼入第 2 步頁面上的連接碼，按連接。每位使用者使用自己電腦產生的碼；請勿分享連接碼。

Chrome 手動載入步驟參閱 [官方文件](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)（查核日期：2026-10-24）。目前尚未上架 Chrome 商店。

### 讀取、翻譯與保存

- **讀取字幕／轉錄**：有可讀字幕時先擷取字幕；無可讀字幕時嘗試下載音訊轉錄。也可按「強制轉錄」。平台限制仍可能導致失敗，並非所有影片都能處理。
- **時間戳**：逐字稿點時間可跳轉目前影片。轉錄處理整支影片，網址的起始秒數不限制處理範圍。
- **翻譯設定**：選「英文→繁體中文」或「簡體→繁體中文」，按「執行翻譯」。可設定自動套用翻譯，以及原文＋譯文／僅譯文／僅原文。
- **摘要**：在摘要分頁查看。預設為本機重點摘錄，並非生成式改寫；Ollama AI 摘要需另行安裝本機文字模型。
- **匯出**：可保存 TXT、SRT、JSON 或摘要；逐字稿匯出遵循翻譯顯示選項。換影片前請匯出需要的結果。

第一次轉錄與英翻中需連網下載模型，簡轉繁不需英翻中模型；請等待進度完成。模型通常保留於本機 `models`。語音辨識、翻譯及時間戳可能有誤，請對照原音。

### 下次啟動、更新與排除問題

- 每次使用先執行 `啟動擴充功能服務.cmd`，再開啟影片工具；服務重啟後，重新複製新連接碼配對。
- 找不到工具：確認已載入正確資料夾並啟用擴充功能，再重新整理影片頁面。
- 顯示未連線：確認本機服務正在執行，並使用這次服務產生的碼。
- 更新時先結束舊服務，新 ZIP 解壓到新資料夾，再到擴充功能管理頁移除舊版並載入新資料夾，使用新連接碼。重新安裝可能清除舊設定與最近結果，請先匯出。
- Windows 執行檔為未數位簽章預覽版；其他系統尚未提供對應執行檔。下載包不要求安裝 Python、Git 或 GitHub CLI。
