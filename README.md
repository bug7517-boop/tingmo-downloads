## 第一次安裝

1. 完整解壓縮到固定資料夾，例如 `C:\AI-Tools\Tingmo`；不要在 ZIP 內執行。
2. 雙擊 **啟動擴充功能服務.cmd**，保持服務執行，本機連線頁會開啟。
3. Chrome 輸入 `chrome://extensions`，開啟「開發人員模式」，點「載入未封裝項目」，選解壓後的 **chrome-extension** 資料夾。
4. 開啟或重新整理 YouTube／Bilibili 影片，點右下角「影片轉文字」按鈕或工具列圖示，進入聽墨面板。
5. 展開「本機服務連線」，貼上自己電腦連線頁的連接碼，按連接。每次服務重新啟動後需要使用新的碼；不要分享連接碼。

安裝資料夾請保留。這是手動載入的預覽版，尚未上架 Chrome 商店；Windows 執行檔未數位簽章。SHA256SUMS.txt 提供下載檔完整性校驗，第三方授權在包內 LICENSES/ 與 THIRD-PARTY.txt。

## 七類轉錄詞庫

展開 **轉錄用字與準確度**，可選自動基本提示或手動詞庫：

| 類別 | 涵蓋用字 |
| --- | --- |
| 人文社會 | 歷史、哲學、文化、法律、社會議題 |
| 心理人際 | 心理、情緒、溝通、人際關係、親子 |
| 健康運動 | 營養、健身、運動訓練、健康照護 |
| 生活與創作 | 烹飪、烘焙、攝影、剪輯、設計、音樂、手作 |
| 科技與程式 | AI、程式、資料庫、資安、網路、硬體 |
| 思維知識類 | 財經商業、思維成長、銷售業務話術、NLP |
| 靈性成長 | 塔羅占卜、易經、西塔、玄學 |

思維知識類的 NLP 按「神經語言程式學」處理；科技類 NLP 為「自然語言處理」。僅出現縮寫時不強行判類。舊版 ai／sales／tarot 設定分別轉為科技與程式／思維知識類／靈性成長。

**自動基本提示**從影片標題及第一輪轉錄取得詞彙，符合關鍵詞時帶入相關詞庫；這不是完整語意理解。可另貼上最多 500 字的產品名、人名等自訂詞彙，目前不提供 TXT／CSV 詞庫檔案匯入。

有提示詞時會重新辨識整段音訊，不會把「歧視」一律替換成「騎士」。兩輪處理會較久，時間分段可能不同；可展開第一輪初稿核對。JSON 匯出保留 rawCues 和 transcriptionContext，包括使用的詞庫與提示詞。詞庫只提示辨識用字，不代表影片內容或相關說法已獲查證。

預設 **基本詞彙提示（不使用語意模型）**，不用安裝 Ollama。Ollama 語意分析及生成式摘要均為選用功能，需另有適合的模型；本版不自動安裝文字模型，也未驗證真實語意模型效果。

## 日常使用

- **讀取字幕／轉錄**：優先讀字幕，沒有可讀字幕時嘗試音訊轉錄。要對原有字幕影片套用轉錄詞庫，請按「強制轉錄」。
- **語音模型**：預設 base，可選 small 或 medium。較大模型需下載，速度較慢、較耗記憶體；未保證特定影片準確率一定改善。
- **時間戳**：點句子時間可跳轉同一影片。處理整支影片，網址的起始秒數不限制轉錄範圍。
- **翻譯**：選英文→繁體中文或簡體→繁體中文，再執行翻譯。可設定自動翻譯及原文／譯文顯示。
- **摘要**：預設為本機重點摘錄，並非生成式改寫。翻譯與摘要使用目前辨識結果。
- **匯出**：TXT、SRT、JSON 或摘要；逐字稿匯出遵循顯示選項。換影片前先保存結果。

首次轉錄或英翻中需連網下載模型；簡轉繁不下載英翻中模型。平台可能拒絕字幕或音訊請求，並非所有影片都能處理。辨識、翻譯、領域判斷與時間戳都可能出錯，請核對原音；尚未以人工參考稿測得本版的準確率改善。

## 更新與排除問題

2026-10-26 新增同一版本的完整更新包，原 1.2.0 與 1.3.1 完整包保留。

1. 先匯出需要的結果，關閉舊本機服務。
2. 下載上方更新包並完整解壓到原工具資料夾內的新子資料夾，執行 `Apply-Update.cmd`。若未自動找到，輸入原工具資料夾完整路徑。
3. 更新器備份原 `chrome-extension` 與啟動器，將新版服務放進 `versions/chrome` 獨立資料夾；原根目錄的執行檔與 `models` 保留。
4. 執行原位置的 **啟動擴充功能服務.cmd**。在 `chrome://extensions` 對原有項目按「重新載入」，重新整理影片，以新連接碼配對。沿用原項目及路徑，不要移除重裝。
5. 如需還原，先關閉服務，執行更新器顯示的備份資料夾內 `Restore-Update.cmd`，再重新載入擴充功能及配對。新版服務資料夾仍會保留。

原始碼開發專案只在現有來源已具七類詞庫時保存更新包與備份，避免覆蓋其他開發功能；重啟原服務及重新載入即可。更新包也包含完整服務，並非小型差異檔，執行檔未數位簽章。

找不到工具時，確認擴充功能已啟用並重新整理影片。未連線時，確認本機服務正在執行並使用本次產生的連接碼。記憶體不足時可先選 base 並關閉其他大型程式後再試。
